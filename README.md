# GBM_morphodynamics

## Requirements

The code was tested in the Conda environment with Python 3.12.13 and the following package versions:

- Python 3.12.13
- NumPy 2.4.6
- pandas 3.0.3
- Matplotlib 3.11.0
- SciPy 1.17.1
- OpenCV 4.13.0
- scikit-image 0.26.0
- scikit-learn 1.9.0
- umap-learn 0.5.12
- tqdm 4.68.2


`src/data_save[1]/manual_marking.csv` is a manually generated file that indicates
whether each spheroid is invasive or non-invasive.

This folder contains analysis code and output folders for extracting morphological features from spheroid/cell morphology images and MarsNet masks, then visualizing time-window-averaged features with UMAP.

The overall workflow is approximately as follows.

1. `get_dataset_info.py` defines the raw data locations, condition names, spheroid numbering rules, and mask-cleanup parameters for each experiment.
2. `get_region_prop2.py` reads the raw `png` images and `mask` images, then saves morphology features, contour features, PCA features, and spectral power features as `.npy` files.
3. `data_read_temp.py` reads the saved feature files and the manual marking CSV, then builds the feature matrix used for UMAP analysis.
4. `multi_time_umap.py` computes the mean spheroid trajectory feature for multiple time windows, then saves UMAP figures and `.npy` results.
5. `feature_extraction_lib.py` and `spectral_power_functions.py` contain helper functions for feature extraction, contour processing, normalization, and visualization.

## File Descriptions

### get_dataset_info.py

This is a configuration file that defines dataset paths and naming rules for the experiments.

Main global variables:

- `base_path`: root path where the raw data are stored. The current value is `../data`.
- `dataset1_info`: dictionaries containing the conditions, folder naming rules, and mask post-processing parameters for each experimental dataset.
- `dataset_info_all`: the full dataset registry in the form `{1: dataset1_info}`. 


Main fields in each dataset dictionary:

- `target_path`: glob path used to find target spheroid folders.
- `target_path_rec`: relative path used to reconstruct image/mask paths.
- `condition_str`: mapping from condition-name strings to numeric codes `(condition_num, env_num)`.
- `condition_str_rev`: reverse mapping from numeric codes back to condition-name strings.
- `png_folder`: raw image folder name. The default is `png`.
- `mask_folder`: mask image folder name. The default is `mask`.
- `png_format`: glob pattern for frame image files. Example: `????.png`.
- `png_format_rec(fr_num)`: function that builds a file name from a frame number. Example: `0001.png`.
- `spheroid_format`: regular expression used to find the spheroid number from a folder name.
- `spheroid_format_rec(sp_num)`: function that builds the spheroid suffix from a spheroid number.
- `exception_file`: marker file used to exclude a folder from analysis when present. Current value: `err.txt`.
- `remove_object`, `remove_hole`: pixel thresholds used for removing small objects and holes during mask post-processing.

Main functions:

- `img_mask_path_fun(rec_ind1)`: receives a record index in `rec_ind` format and returns the raw image path, mask path, mask-cleanup parameters, and title.
- `get_rec_ind_title(rec_ind1)`: converts a `rec_ind` value into a human-readable title string. Example: `ex_1_Fibrin_Ctl_1_001`.

`rec_ind` format:

```text
[experiment_number, condition_number, environment_number, spheroid_number, frame_number]
```


### get_region_prop2.py

This is the main preprocessing script that reads raw images and masks, then extracts morphology and contour features.

Behavior when executed:

1. Reads `base_path` and `dataset_info_all` from `get_dataset_info.py`.
2. Iterates through the target folders for each dataset.
3. Analyzes only frames where both `png` and `mask` files exist.
4. Binarizes each mask using Otsu thresholding, then removes small objects and holes.
5. If multiple connected components exist, selects the largest component as the spheroid region.
6. Computes region properties from the selected mask and the raw grayscale image.
7. Reduces the mask boundary contour to 256 points and aligns it by the major axis.
8. Computes PCA features, raw power spectrum, and normalized spectral power from the contour.
9. Saves `.npy` files and the PCA reducer to `./data_save[1]` when the script is run from `src`.

Main functions:

- `get_num_from_folder_name(folder_name, spheroid_format, condition_str, exp_num=0)`: extracts the experiment number, condition number, environment number, and spheroid number from a folder name.
- `get_png_mask_match(path1, png_folder, mask_folder, png_format)`: pairs raw image and mask files that have the same frame number.
- `get_img_mask_rec_form_dataset_info(dataset_info, ex_day=0, base_path='./')`: creates `rec_ind`, `prop_arr`, and `contour_arr` for one dataset.

Main saved files:

- `rec_ind.npy`: experiment/condition/spheroid/frame index for each row.
- `prop_arr.npy`: region property feature array.
- `contour_arr.npy`: aligned and reduced contour array.
- `pca_arr.npy`: PCA embedding of Fourier contour features.
- `power_spec_arr.npy`: Fourier power spectrum of the contour.
- `power_norm_arr.npy`: normalized/weighted spectral power.
- `pca_reducer.pickle`: PCA transformer object.
- `pca_feature_result/`: plots showing contour changes along PCA axes and reconstruction tests.

Notes:

- Before execution, `base_path` in `get_dataset_info.py` must point to the actual raw data location.
- The output folder name is generated as `./data_save` + `str(list(dataset_info_all.keys()))`. With the current dataset configuration, the output is `./data_save[1]` (`src/data_save[1]` from the repository root).
- If no component is found in a mask, the script may stop at `pdb.set_trace()`.


### feature_extraction_lib.py

This library contains morphology feature, contour feature, PCA feature, and visualization utilities. It is mainly used by `get_region_prop2.py` for feature extraction.

Main functionality:

- Computes region properties from a binary mask
- Extracts contours from a binary mask and performs major-axis rotation
- Reduces contour point count to a fixed length
- Builds Fourier contour features
- Trains and restores PCA representations of Fourier contour features
- Computes power spectrum features
- Performs z-score normalization
- Filters/tokenizes data based on record indices
- Generates diagnostic plots for PCA features

Important functions:

- `get_region_prop(mask1)`: computes 10 morphology features from a mask.
- `get_region_prop2(mask1, png1)`: computes 13 features from a mask and raw intensity image.
- `binary_mask_to_reduced_contour(binary_mask, contour_dim=None, major_rot=True)`: finds the longest contour, aligns it using centroid/major-axis information, and optionally reduces the number of points.
- `fourier_contour_feature_pca(contour_all, dim=5)`: builds features from FFTs of contour x/y coordinates and trains PCA.
- `restore_pca_contour_feature(pca_value, reducer)`: restores a contour from PCA features.
- `power_spectrum_feature(contour_all)`: computes contour FFT-based power spectrum features.
- `sigma_plot(...)`: saves how contour shape changes when each PCA axis is varied by sigma units.
- `recon_test1(...)`: saves plots to inspect contour reconstruction quality when PCA dimensions are limited.
- `sp_csv_gen(rec_ind, save_path='R:/temp.csv')`: saves spheroid-level `rec_ind` values and names to a CSV file.

Columns of `prop_arr` generated by `get_region_prop2()`:

```text
0  filled_area
1  major_axis_len
2  minor_axis_len
3  perimeter
4  convex_area
5  eccentricity
6  extent
7  solidity
8  circularity
9  aspect_ratio
10 orientation
11 intensity_mean_background_corrected
12 intensity_std_inside_mask
```


### spectral_power_functions.py

This file contains functions for computing Fourier/spectral power from contours. The original code handled boundary coordinate files and image files, and additional functions were added for mask/contour arrays.

Main functionality:

- Computes contour length
- Interpolates contours onto evenly spaced grids
- Computes contour area
- Performs real FFT/rFFT and inverse transform
- Computes Fourier power
- Normalizes power using the first Fourier component
- Computes weighted spectral power

Important functions:

- `get_contour_length(points)`: computes cumulative length along a contour point sequence.
- `get_interpolate(points, contour_in, contour_out)`: interpolates a contour onto an even arc-length grid.
- `get_area(points)`: computes polygon area.
- `get_rfft(points_grid)`: computes real FFT for each contour coordinate.
- `get_power(points_rfft)`: sums the power of Fourier coefficients for x/y coordinates.
- `compute_weighted_spectral_power(power_norm)`: computes a scalar weighted spectral power from a normalized power spectrum.
- `get_norm_spectral_power_from_contour_arr(contour_arr)`: computes weighted spectral power for the full `contour_arr` and returns an `(N, 1)` array.

Notes:

- `get_norm_power_from_mask1()` still contains `pdb.set_trace()`, so calling it directly will stop in the debugger.
- `match_coord_image()` uses the Python 2-style `string.replace`, so it may not work as-is in a Python 3 environment. It is not part of the core analysis pipeline currently used here.


### data_read_temp.py

This helper file reads saved `.npy` feature files and the manual marking CSV, then builds a feature matrix for downstream analysis. It is used by `multi_time_umap.py`.

Main global variables:

- `prop_title_dict`, `prop_title_list`: names of the `prop_arr` columns.
- `feature_weight`, `alpha`, `attempt_num`: settings that appear to be for some experiments/visualizations, but are only used in a limited way in the current main pipeline.

Important functions:

- `base_data_read(data_save_path_list, feature_sel_dict)`: reads feature files and `manual_marking.csv` from multiple `data_save` folders, then merges them into one dictionary.
- `get_value_from_manual_masking(rec_ind, manual_mask_pd, ...)`: maps spheroid-level labels from the manual marking CSV to frame-level `rec_ind` rows.
- `rec_to_ind(rec, key)`: returns a row mask for entries in a `rec_ind` array that match a specific key.
- `rec_to_inter_keys(rec, sort=True)`: extracts unique keys from a `rec_ind` array.
- `cell_tokenizer(rec, return_inter=False)`: assigns integer tokens to unique spheroid/condition combinations.
- `get_flux_mean_fr_win(data_win_list, rec_flux, rec_win)`: computes mean frame-level data values corresponding to a time-window record.
- `draw_label_umap_marked(...)`: draws and saves a scatter plot of 2D UMAP coordinates colored by label.

Files read by `base_data_read()`:

- `rec_ind.npy`
- `prop_arr.npy`
- `contour_arr.npy`
- `pca_arr.npy`
- `power_spec_arr.npy`
- `power_norm_arr.npy`
- `manual_marking.csv`

Meaning of columns in `manual_marking.csv`:

- `rec_ind0`, `rec_ind1`, `rec_ind2`, `rec_ind3`: spheroid ID. These are the same identifiers as `rec_ind[:, :4]` in the code and point to one spheroid trajectory.
- `sp_name`: folder name containing the corresponding spheroid information. This value is included as a validation field to check that `rec_ind0`-`rec_ind3` match the actual folder.
- `is_invasive`: manually recorded label indicating whether the spheroid appeared invasive by visual inspection. `1` means invasive, and `0` means not invasive.

`base_data_read()` maps the spheroid-level `is_invasive` labels in this CSV to frame-level `rec_ind` rows and returns them as the `manual_invasive` array.

Dictionary returned by `base_data_read()`:

- `prop_arr`
- `prop_arr_stand`
- `contour_arr`
- `pca_arr`
- `power_spec_arr`
- `power_norm_arr`
- `rec_ind`
- `feature_arr`
- `feature_arr_norm`
- `manual_invasive`

Notes:

- `manual_marking.csv` must exist inside each `data_save` folder.
- `data_list_for_plot1()` and `data_list_for_plot2()` currently call `base_data_read()` without arguments, so they may fail if executed as-is.


### multi_time_umap.py

This analysis script computes mean spheroid trajectory features across multiple time windows and generates UMAP embeddings.

Current main settings:

- `att_num = 1`
- `data_save_path_dict[att_num] = ['./data_save[1]']`
- UMAP options: `min_dist=0.05`, `n_neighbors=4`, `random_state=200`
- Frame step: `fr_step = 6`

Feature selection:

The current analysis uses `att_num = 1` and the following feature selection:

- Raw properties: `prop_sel = [8, 7, 3, 6, 4]`
- Standardized in each dataset properties: not used
- PCA features: not used
- Raw power spectrum: not used
- Normalized spectral power: `[0]`

Therefore, the current UMAP input contains these six features:

- `circularity`
- `solidity`
- normalized/weighted spectral power
- `perimeter`
- `extent`
- `convex_area`


Behavior when executed:

1. Reads features and manual labels using `DRT.base_data_read(...)`.
2. Builds spheroid trajectory keys based on `rec_ind[:, :4]`.
3. Computes the maximum frame range shared by all trajectories.
4. Creates time windows by changing the start frame and window length at intervals of `fr_step=6`.
5. Computes the mean normalized feature vector for each spheroid trajectory within each time window.
6. Fits/transforms UMAP on the time-window-specific `data_mean` array.
7. Saves UMAP scatter plots labeled by condition/type and manual invasive label.
8. Saves some result dictionaries as `.npy` files.

Output folders:

- `./01_data_mean1`
- `./01_data_mean2`

Example output file names:

- `100_type_st_00_len_07.png`
- `100_inv_st_00_len_07.png`
- `100_data_st_00_len_07.npy`

File name components:

- Leading number: plot index
- `type`: UMAP labeled by spheroid/condition type
- `inv`: UMAP labeled by manual invasive label
- `st_XX`: starting frame of the time window
- `len_XX`: length of the time window


Notes:

- The `umap-learn` package is required. The import name is `umap`.
- Paths in `data_save_path_dict` must match the actual feature-save folder names.
- If `manual_marking.csv` is missing or cannot be matched to `rec_ind`, the assertion in `base_data_read()` may fail.

## Data/Index Rules

`rec_ind` is the main index used to identify data across most files.

```text
rec_ind[:, 0] = experiment number
rec_ind[:, 1] = condition number
rec_ind[:, 2] = environment number
rec_ind[:, 3] = spheroid number
rec_ind[:, 4] = frame number
```

`rec_ind[:, :4]` is used as the key identifying one spheroid trajectory, and `rec_ind[:, 4]` is used as the time frame.


## PHet Feature Selection

Feature selection was performed using PHet after the morphological features had been extracted.

1. Download and install [PHet](https://github.com/kleelab-bch/phet) according to its installation instructions.

2. After completing feature extraction, run `phet_data_gen.py`:

   ```bash
   cd src
   python phet_data_gen.py
   ```

   It generates the PHet input dataset at the following location:

   ```text
   src/phet_dataset/type_invasive_subtype_condition/
   ├── ML_analysis_2-4_types.csv
   ├── ML_analysis_2-4_classes.csv
   ├── ML_analysis_2-4_feature_names.csv
   ├── ML_analysis_2-4_matrix.mtx
   └── result/
   ```

3. Copy the dataset generated by `phet_data_gen.py` into the `data` directory of the downloaded PHet repository.

4. From the `src` directory of the PHet repository, run PHet according to its usage guidelines. The following command was used in this study:

   ```bash
   python main.py \
     --dspath ../data \
     --rspath ../result \
     --file-name "ML_analysis_2-4" \
     --suptitle-name "ex_1_invasive" \
     --control-name "Not invasive" \
     --case-name "Invasive" \
     --methods phet_br \
     --num-neighbors 300 \
     --min-dist 0.05 \
     --alpha 0.01 \
     --score-metric "f1" \
     --top-k-features 10 \
     --cluster-type "kmeans" \
     --num-jobs 8 \
     --no-sort-by-pvalue
   ```

5. After execution, PHet writes the feature scores to a file ending in `_features_scores.csv` in its `result` directory. With the current file name, the output is `ML_analysis_2-4_phet_br_features_scores.csv`. The features used in the subsequent analysis were selected based on these scores.
